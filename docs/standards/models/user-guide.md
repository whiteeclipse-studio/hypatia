# User guide model

An optional starting point for task-oriented instructions. See the [standards entrypoint](../README.md) and [user guide standard](../categories/user-guides.md).

## Using this model

Copy the template to `docs/public/guides`, using a descriptive filename or `README.md` for a folder entrypoint. Replace placeholders, select the adopted standards entrypoint revision, and adjust links for the final location. The headings below are suggestions; organize the guide around the task and omit the optional success criteria if unnecessary.

## Copyable template

```markdown
---
id: guide-subject
standard_revision: 1
---

# Task

Briefly explain the task and intended outcome.

## Prerequisites

Identify relevant versions, permissions, and setup needed before starting.

## Instructions

<!-- Explain consequences before any destructive or irreversible action. -->

1. Describe the first action.
2. Continue in the order readers need to follow.

<!-- Optional: describe the expected result and how readers can recognize success. -->
```
