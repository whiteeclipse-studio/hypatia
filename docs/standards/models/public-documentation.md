# Public documentation model

An optional starting point for general information shared with people outside the project. See the [standards entrypoint](../README.md) and [public documentation standard](../categories/public-documentation.md).

## Using this model

Copy the template to `docs/public`, using a descriptive filename or `README.md` for a folder entrypoint. Replace placeholders, select the adopted standards entrypoint revision, and adjust links for the final location. Organize the content freely around its subject.

## Copyable template

```markdown
---
id: public-subject
standard_revision: 1
---

# Subject

Briefly explain what this document communicates and who it is for.

<!-- Add the information to share publicly, using headings as useful. -->

## Copyright and licence

Copyright © YYYY Copyright Holder.

Released under [Licence Name](https://example.com/LICENCE).

## Revisions

| Revision | Date       | Author       | Description   |
| -------- | ---------- | ------------ | ------------- |
| 1        | YYYY-MM-DD | Human Author | Initial draft |
```
