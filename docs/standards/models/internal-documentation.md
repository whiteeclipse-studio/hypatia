# Internal documentation model

An optional starting point for information shared within the project. See the [standards entrypoint](../README.md) and [internal documentation standard](../categories/internal-documentation.md).

## Using this model

Copy the template to `docs/internal/reference`, using a descriptive filename or `README.md` for a folder entrypoint. Replace placeholders, select the adopted standards entrypoint revision, and adjust links for the final location. Organize the content freely around its subject.

## Copyable template

```markdown
---
id: internal-subject
standard_revision: 1
---

# Subject

Briefly explain what this document communicates and who it is for.

<!-- Add the information to share internally, using headings as useful. -->

## Copyright and licence

Copyright © YYYY Copyright Holder.

Released under [Licence Name](https://example.com/LICENCE).
```
