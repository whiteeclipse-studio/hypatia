# Documentation standards

This is the entrypoint to Hypatia’s documentation standards. Shared standards define common rules; category standards cover specific document types. See the [documentation entrypoint](../README.md).

## Requirement terminology

In this file and all files under `docs/standards`, uppercase requirement keywords follow **BCP 14**, as defined by [RFC 2119](https://www.rfc-editor.org/rfc/rfc2119) and [RFC 8174](https://www.rfc-editor.org/rfc/rfc8174). These meanings apply only to fully uppercase keywords; lowercase forms retain their ordinary meaning.
