# Internal documentation standard

This standard defines documentation intended to communicate information within the project. See the [standards entrypoint](../README.md).

## Rules

### Location and scope

- Internal documentation MUST reside in `docs/internal/reference`.
- Filenames MUST use descriptive lowercase `kebab-case`, except for `README.md` entrypoints. Related subjects MAY be grouped into subfolders.
- Internal documentation are intended for the project's internal audience. Publication MUST preserve that audience restriction, following the [publication standard](../PUBLICATION.md).

## Reusable model

The [internal documentation model](../models/internal-documentation.md) provides an optional starting point.
