# Public documentation standard

This standard defines documentation intended to communicate general information to people outside the project. See the [standards entrypoint](../README.md).

## Rules

### Location and scope

- Public documentation MUST reside in `docs/public`, except where another category standard defines its location.
- Filenames MUST use descriptive lowercase `kebab-case`, except for `README.md` entrypoints. Related subjects MAY be grouped into subfolders.
- This category covers general public-facing information. User guides and API documentation belong to their own categories.

## Reusable model

The [public documentation model](../models/public-documentation.md) provides an optional starting point.
