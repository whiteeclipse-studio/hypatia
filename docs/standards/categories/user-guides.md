# User guide standard

This standard defines documentation that helps users complete tasks with the project. See the [standards entrypoint](../README.md).

## Rules

### Location and scope

- User guides MUST reside in `docs/public/guides`.
- Filenames MUST use descriptive lowercase `kebab-case`, except for `README.md` entrypoints. Related guides MAY be grouped into subfolders.
- Each guide MUST focus on a clearly identified task or outcome.

### Guide content

- Guides MUST identify prerequisites, including applicable versions, permissions, and setup where relevant.
- Instructions MUST present actions in the order readers need to perform them.
- Guides MUST explain the consequences of destructive or irreversible actions before readers perform them.
- Guides MAY include success criteria explaining the expected result and how readers can recognize it.

## Reusable model

The [user guide model](../models/user-guide.md) provides an optional starting point.
