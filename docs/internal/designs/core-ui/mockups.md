# Core UI — Mockups

Part of the [design proposal](README.md).

## Overview

These retained captures illustrate the previous Core UI palette, typography, corner-frame controls, flat surfaces, branding, and optional background. They are visual references for the proposed styled theme and owned component library. All sample descriptions and recorded checks below refer to the pre-rewrite implementation; the sources now link to its fixed Git snapshot.

The landing is an illustrative Core UI composition, not a definitive website design. See the [inspirations](inspirations/README.md), [implementation rules](implementation-rules.md), and [component catalogue](components.md) for the new proposal.

## Samples

### Landing reference

![Illustrative landing composition](assets/core-ui-mockups-landing-design-composition.jpg)

_Full-page light-theme capture from Storybook, 2026-10-18, at 1280px width. This is a sample composition for Core UI review, not a final page proposal. Header, hero, studio statement, four services, blog/contact sections, and footer demonstrate reusable hierarchy and grouping. The wording, section order, service descriptions, destinations, image placement, and disabled placeholders are illustrative. The full-page capture shows composition; the viewport/scrolled samples below demonstrate fixed-background behaviour._

![Landing reference in light appearance](assets/core-ui-mockups-background-fixed-light.jpg)

_Exploratory Storybook viewport capture, 2026-10-18, at 1280 × 720px. The user-supplied Cydonia desktop landing concept informs the section order, editorial hierarchy, and column proportions. Generated transparent orbital and eclipse images replace the earlier empty frames. Font Awesome supplies the service icons, arrows, and social icons. The header and footer use the supplied company logo, with the matching asset selected from the active Core UI appearance._

![Landing reference in dark appearance](assets/core-ui-mockups-background-fixed-dark.jpg)

_Same sample at 1280px with the shared dark appearance. Both captures are browser-rendered component compositions and remain unapproved design references._

![Background during scroll](assets/core-ui-mockups-background-scrolled.jpg)

_Light-theme 1280 × 720px viewport capture, 2026-10-18, scrolled into the studio/services area. The geometric drawing retains its viewport position while content moves. It is decorative and does not intercept input. This capture is evidence of the prototype observation, not a contrast or cross-browser certification._

### Documentation website reference

![Documentation reading shell in light appearance](assets/core-ui-mockups-documentation-light.svg)

![Documentation reading shell in dark appearance](assets/core-ui-mockups-documentation-dark.svg)

_Illustrative desktop wireframes, 1280 × 1080px, authored on 2026-10-20. These SVG assets approximate the composition and use the shared theme palette and supplied logo; they are not browser captures or evidence of rendered behaviour. Text wrapping, spacing, disclosure markers, and the abbreviated article are illustrative. The wireframes name Inter, Outfit, and JetBrains Mono with fallbacks; they do not embed font files or load Google Fonts, so SVG image previews may use fallback fonts. Their static background approximates the desktop geometry and does not demonstrate viewport-fixed scrolling. The full sample includes a publication callout and article footer beyond this composition._
