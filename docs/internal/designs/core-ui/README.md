# Core UI

Core UI defines White Eclipse's foundational UI framework and toolchain, providing consistent visual foundations and basic interaction building blocks across applications.

## Scope

Core UI provides shared design tokens, themes, typography, layout primitives, basic controls, and styling utilities. Applications compose these foundations into their own experiences.

Application-specific compositions, complex feature components, business logic, routing, data access, and localization behaviour are outside its scope.

The shared visual foundations can also support a native Obsidian theme as a derivative application of the framework.
