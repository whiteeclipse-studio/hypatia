# Core UI — Inspirations

Core UI draws its visual direction from NieR: Automata and uses Radix Themes as its technical foundation. Part of the [design proposal](../README.md).

## Sources

- [NieR: Automata](./nier-automata.md): visual inspiration and its connection to the White Eclipse identity.
- [Radix Themes](./radix-themes.md): styled foundation, shared tokens, and component behaviour.
